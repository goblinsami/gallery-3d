# Project Philosophy

## Principles
- Config-first runtime, not editor-first platform.
- Deterministic cinematic behavior over ad-hoc animations.
- Clear separation of concerns beats feature density.
- Runtime portability: app preview + web component + adapter integrations.

## Engineering Bias
- Strong typing and validation at boundaries.
- Reusable factory modules for scene composition.
- Performance-aware defaults and explicit cleanup.
- Backward compatibility for renamed config keys where practical.

## AI Collaboration Bias
- Low-token summaries first, deep files second.
- Preserve existing patterns before introducing new abstractions.
- Keep parity between app runtime and packaged runtime surfaces.
